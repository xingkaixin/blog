# 节日 Logo 日期配置

日期在本地项目的 [`config/holiday-logos.json`](../config/holiday-logos.json) 中维护。
部署版本按这份配置选择页眉 Logo，不提供网页设置页。

- `fixedDates`：固定月日，格式为 `MM-DD`，每年沿用。
- `annualDates`：逐年填写农历节日和节气对应的公历月日。
- `priorities`：同日有多个事件时，数值较高的优先；未填写的项目默认 10。
- `disabled`：暂停使用的 Logo ID。
- `timeZone`：按 `Asia/Shanghai` 的日历日期匹配。

三个生日为固定公历日期：

| 日期  | Logo ID           | 名称     |
| ----- | ----------------- | -------- |
| 05-04 | `father-birthday` | 父亲生日 |
| 07-12 | `mother-birthday` | 母亲生日 |
| 12-05 | `birthday`        | 我的生日 |

青年节和站点周年不收录。

每年添加下一年的 `annualDates`，核对除夕、春节、元宵、春分、清明、端午、夏至、七夕、秋分、中秋、重阳、冬至十二项。
四季系列使用春分、夏至、秋分和冬至，日期也按年填写。
未填写的年份只匹配固定日期，不复用上一年的农历日期。
核对来源保存在配置文件的 `sources` 中。

构建时校验 Logo ID、日期和优先级。页面加载、返回浏览器标签页及上海午夜会重新匹配日期；普通日期使用日常 Logo。

图形与说明分别维护在 `public/holiday-logos/` 和 `src/lib/holiday-logos.ts`。
`description` 介绍日子本身的习俗或意义，`theme` 是对应 Logo 的款式名称。
每款包含白天和颠倒世界两个 SVG，暗色图形已包含字形翻转，不能再整体旋转图片。

展示页为 `/lab/logos/`，从命令面板的「实验 → 节日 Logo」进入。
展示页是可以把玩的徽章工坊：点击徽章按压回弹，转动外圈浏览全年，也可以按四季节点或收藏架切换。支持昼夜翻转、图层拆解、放大查看和临时投到页眉。
音效默认关闭；静止按钮暂停动效，系统减少动态效果偏好同样生效。罗盘支持方向键和 Home/End，键盘操作直接切换。
页眉预览只影响当前页面，离开后恢复按日期匹配，不修改配置。不提供 SVG 下载入口。

每个 SVG 保留原图，并通过 `logo-shell`、`logo-core`、`logo-details` 三个分组暴露外壳、字形与前景装饰。实验台用外部 SVG `use` 引用这些分组，拆解时移动真实图层。新增图形时保持这些 ID，以及原来的绘制顺序；没有前景装饰时保留空的 `logo-details` 分组。

新增实验项目时维护 `src/lib/experiments.ts`，命令面板和 Sitemap 会同步读取。
