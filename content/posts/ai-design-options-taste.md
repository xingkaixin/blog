我前几天看独立开发者 Takuya Matsuyama 发了一段视频。他给自己的 Markdown 笔记应用 Inkdrop 重做落地页，把市面上能叫得出名字的 AI 工具试了个遍。

一圈折腾下来，几个模型各给了一个高分方案。有的像硅谷大厂的标准化官网，有的把富士山和产品界面融在一起、视觉完成度极高，有的带着浓郁的日式极简风，还有一个是用 GitHub 上 11 万星的提示词库跑出来的 Apple 和 Stripe 混合体。

换成一般的开发者，挑其中任何一个直接上线，发到社交网络上都能引来一堆点赞。

但他把这四套方案全都关掉了，一个都没用。

最后正式上线的版本，是他把客户端里的真实 React 组件抽出来，做成了一个可以在浏览器里直接打字试用的交互 Demo。

看完整期视频我最大的触动是：我们总以为用 AI 搞界面，难点在于怎么调教模型的审美。但在这个案子里，把那四套高分方案一个个枪毙掉的，从头到尾都跟美丑无关。

Takuya 尝试的第一轮是 v0，输入几版提示词，吐出来的是标准到近乎刻板的 SaaS 页面。灰白底色、分栏功能点，挑不出什么大 Bug，但他看了一眼就觉得索然无味，随手关掉了。

第二轮他换用图像生成模型直接出概念图。出来的效果瞬间把他震住了：背景是一座雄伟的富士山，前景端正地压着暗色调的编辑器界面，底下四个信息块排布得极其考究。单论视觉冲击力和第一眼惊艳度，几乎无可挑剔。

但他很快意识到一个严重的问题：如果一个陌生访客被背景里的富士山勾走了全部注意力，他根本不可能有耐心去研究前景里的笔记软件到底有什么用。

为了说明这点，他在视频里提到了自己一直很崇拜的设计师 Oğuz Yağız Kara。Oğuz 在圈内以华丽的 3D 动画和 WebGL 交互著称，作品拿过无数设计大奖。但 Takuya 仔细复盘后发现，看那些得奖作品时，自己的注意力全在跟着绚丽的动效乱转，看完甚至记不住那个产品究竟解决了什么问题。

落地页不是艺术展，访客如果五秒钟内弄不懂这个软件是干嘛的，图画得再震撼，对一个单兵作战的独立产品来说也是负资产。

![背景抢走产品注意力](/posts/images/ai-design-options-taste/ai-design-options-taste-01.png)

第三轮他用 Claude 生成网页代码，特意融入了日本传统的“一汁一菜”生活理念，希望传达出少即是多的克制感。

版式确实很有新意，但正文里的日文字符全成了乱码，布局在小屏上也碎掉了。更关键的是，Claude 写的 CSS 带着一股极其顽固的模板味。只要你平时经常看各种 AI 生成的独立项目，一眼就能认出那种完全雷同的渐变和阴影。他的原话非常不留情面：他实在讨厌这种“品味上的泔水”。

第四轮他找来了 GitHub 上有 11.5 万颗星的开源库 `awesome-design-md`。这个库把 Apple、BMW、Stripe、ClickHouse 这类顶级品牌的设计规则整理成了 system prompt。跑出来的页面依然挑不出毛病，但骨子里就是各大商业公司的平均脸，没有任何属于自己的个性。

除了认知门槛，枪毙掉这些方案的第二道硬卡点是维护成本。

Inkdrop 是一个桌面客户端，作者常年一个人开发，界面隔一两个月就会根据用户反馈调整一次。

如果落地页全靠 AI 生成的高清效果图、手工修饰的 UI mock 和预录制的宣传动画，产品界面只要改个按钮位置，落地页上的整套物料就得重新渲染、重新录屏、重新切图。对于一个人维护的小项目来说，这套维护成本根本不可持续。

否掉这四套方案后，他的最终解法反倒极其接地气：

与其用静态图和动画去向用户解释笔记软件有多好用，不如把客户端里的真实 React 组件抽成独立的 UIKit 库，直接在浏览器里挂载一个 CodeMirror 编辑器。访客点进网页，不需要看介绍，直接在当前页面里就能敲代码、写 Markdown。

![同一组件服务两端](/posts/images/ai-design-options-taste/ai-design-options-taste-02.png)

这一步把两道硬卡点同时化解掉了。

对访客来说，认知成本被直接压平：你不需要在五秒钟里阅读任何文案，手指在键盘上敲两下，输入延迟、语法高亮和排版质感自己会说话。

对单人维护的作者来说，沉重的素材维护税被彻底清零：落地页引用的就是客户端的真实组件，以后客户端改动了布局或样式，核心逻辑升级一次，落地页自动跟着同步，再也不用为截几张图折腾半天。

回过头看这四套被扔进垃圾桶的高分方案，它们其实一点都没浪费。

它们在最短的时间里，帮作者在真实屏幕上把边界全部摸了一遍：富士山代表注意力被劫持的上限，v0 代表平庸的下限，Claude 的默认样式代表大模型的品味均值，大厂规范代表没有灵魂的成熟。

如果关在房间里空想，可能要折腾好几个礼拜才能想明白自己不要什么。

过去大家总以为用 AI 做设计，最大的焦虑在于模型的审美不够好，或者自己没有顶级设计师的品味。但当算力把“看起来很体面”的边际成本压到几乎为零时，大模型在几分钟里就能把几十个挑不出毛病的及格方案砸在你脸上。

生成选项越廉价，真正的品味就越不在于挑选哪张图更好看。

**决定一个产品最后能不能立住的，从来不是模型能画出多惊艳的界面，而是在海量体面的选项面前，你敢依据什么物理硬约束把它们直接丢弃。**

在打开任何设计工具之前，先把两条绝不妥协的底线写死在纸上：访客必须在五秒内弄懂它，以及改版后自己一个人养得起它。只要那两张底牌立得足够硬，面对再多看起来挑不出毛病的华丽方案，你也能面不改色地把它们一个个关掉。
